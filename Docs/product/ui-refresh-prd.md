# 墨织 UI/产品大改版 PRD

版本：0.2 · 2026-03 · 与 `ui-refresh-spec.md` 配套

## 1. 愿景

让墨织在长时间写作场景下具备 **可识别的东方书斋气质**、**低打扰的反馈层** 与 **一致的信息脉络**，同时保证离线、本地优先与现有数据模型不变。

## 3. 功能范围

### 3.1 主题体系（P0）

- 收敛为 5 套：`paper` | `ink` | `fourgentlemen` | `mountain` | `dragon`
- 旧 ID `bamboo` / `plum` / `orchid` / `chrysanthemum` 读取偏好时映射为 `fourgentlemen`
- 每主题提供 `bg.svg`（平铺底纹）与 `preview.svg`（设置卡片）

### 3.2 设置（P0）

- 全屏布局：顶栏（返回、项目名、保存状态）
- 分区：主题、离开策略、数据位置、快照、快捷键、插件、危险操作
- 主题卡片使用预览图；选中态克制（内阴影，非高对比描边框）

### 3.3 搜索（P0）

- 顶栏 Popover：分组、类型图标、匹配高亮、空状态文案
- Esc / 点击外部关闭

### 3.4 词表（P0）

- 关系类型/区间、人物状态、章节状态、故事线类型：允许 `require_vocab_label`（≤16 字）
- 前端统一 `VocabField`（含「自定义…」）

### 3.5 反馈组件（P0）

- Toast、Modal、Popconfirm、Tooltip（轻量自研，Pinia `feedback` store）
- 替换 `window.confirm` 与页面内冗长说明块

### 3.6 排序（P0）

- 时间线：拖拽与按钮共用 `reorderIds` + 后端 `event_reorder`
- 排序列表不以 `title` 二次排序破坏 `sortOrder` 稳定性

### 3.7 导航与图标（P1）

- `lucide-vue-next` 侧栏与工具栏
- 视图切换 Alt+1…8 说明挂载至设置

### 3.8 视图体验（P1）

- 时间线轨道/卡片 stagger；故事线泳道；关系图边动效；`prefers-reduced-motion` 尊重

### 3.9 快捷键可配置（P2 / 本期仅只读）

- 设置展示当前键位；持久化改键留后续迭代

## 4. 非功能需求

- **性能**：主题 SVG 平铺，单文件 &lt; 50KB；动效仅 CSS
- **无障碍**：图标按钮保留 `aria-label`；键盘焦点可见但鼠标选中无外圈
- **兼容**：已有项目 SQLite 无结构变更（主题迁移仅在 preferences）
- **隐私**：数据路径、快照仍仅本机

## 5. 成功指标

见 `ui-refresh-spec.md` 验收表 13 条；全部通过视为本期交付。

## 6. 风险

| 风险 | 缓解 |
|------|------|
| Tauri 打开目录权限 | 使用 `tauri-plugin-opener` 或复制路径为主 |
| 自定义标签筛选不全 | P1：从项目数据 DISTINCT 扩展 `vocab_list` |
| 作者依赖旧四主题 ID | `normalize_theme` 迁移 + 发布说明 |
