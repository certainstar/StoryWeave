# 隐私

墨织是单机开源软件。它不建立账号，也不在开发者的服务器上保存用户信息或小说正文。打开、编辑和搜索项目不需要注册，也不需要网络。

作者如果希望多台设备互通，自己导入项目文件、用自己的远端仓库鉴权，或自行配置同步。这些通路可以接到插件槽上。凭据留在作者本机或作者自己的仓库里，不进入墨织的用户库。

## 现在就成立的约定

- 不保存用户账号、昵称、邮箱或其他个人资料。
- 不上传正文，不采集遥测。如果以后增加匿名统计，必须可以关闭，并在界面里写明收集什么。
- 日志不记录密钥，也不记录正文全文。设置页可以显示项目路径，因为那是作者要找的位置。
- 模型调用不进入第一版。没有可填写密钥的入口，也没有会把正文发出去的按钮。
- 原型里的示例项目只存在于当前页面，不会写入磁盘。

## 以后如果接入模型

远程模型意味着选中的文本会离开本机。那种情况必须同时满足：

1. 作者自己打开模型功能。默认保持关闭。
2. 发送前说明这次会送出哪一段文字，以及送到哪一家服务。
3. 密钥放在系统安全存储或受保护的本地配置里，不写入项目导出文件、日志或版本库。
4. 模型给出的结果先作为候选。作者确认之后才写入人物、关系或事件。

本地模型服务和远程模型不是一回事。界面和数据库在本机，不等于推理也在本机。

## 报告问题

不要在公开 Issue 里粘贴密钥、未发表的正文，或别人的私人材料。安全问题按 [SECURITY.md](../SECURITY.md) 私下报告。
